# Vídeo do prólogo

O jogo já inclui um prólogo cinematográfico interativo. Para substituir ou anteceder esse prólogo com o vídeo final:

1. Coloque o vídeo como `prologo.mp4` nesta pasta.
2. Opcionalmente, coloque legendas WebVTT como `prologo.vtt`.
3. Altere `enabled` para `true` em `video-manifest.json`.

O reprodutor oferece legenda, volume, pausa, tela cheia e botão para pular. Se o arquivo não existir, o prólogo interativo continua funcionando.
