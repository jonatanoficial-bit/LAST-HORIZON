# Checklist de release

- [x] Identidade GSEA; nenhuma alegação de parceria real.
- [x] Campanha completa com recuperação após abortagem.
- [x] Estado centralizado e seed reproduzível.
- [x] Falhas com causa, sintomas, propagação, detecção e mitigação.
- [x] IndexedDB, checksum, autosave, migração, exportação e importação.
- [x] PWA instalável, cache offline e atualização sem apagar saves.
- [x] Paisagem, 640×360, desktop, toque, mouse e teclado.
- [x] Instrumentos codificados e ligados à simulação.
- [x] Acessibilidade, movimento reduzido, paleta daltônica e modo sem som.
- [x] Dados e links auditados; testes unitários e integração causal.
- [x] Nenhum texto de desenvolvimento exibido na interface final.
