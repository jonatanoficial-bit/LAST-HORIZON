# Ordem de uso

1. Leia a Bíblia Oficial em DOCX/PDF.
2. Abra `00_PROMPT_INICIAL_CODEX.md` no Codex.
3. Conclua F00 e valide os critérios de aceite.
4. Use um arquivo de `prompts_codex/` por vez, em ordem.
5. Gere as imagens conforme `data/asset_manifest.csv` e salve com o nome exato.
6. Nunca incorpore instrumentos ou textos nos fundos da cabine.
7. Atualize o manifesto ao substituir ou reprovar uma imagem.
8. Somente publique após F44.
