# Envio pelo Git Bash

Abra o Git Bash dentro do repositório e execute:

```bash
cd "/c/Users/jonat/Desktop/GAME/¨2026/LAST HORIZON"
git status
git add .
git commit -m "Atualização do LAST HORIZON"
git push
```

Se você extrair o jogo em outra pasta, altere somente o caminho do primeiro comando. Antes do `git push`, confira no resultado de `git status` se os arquivos listados pertencem ao jogo.
