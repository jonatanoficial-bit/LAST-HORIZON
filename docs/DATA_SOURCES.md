# Fontes de dados e créditos

## Posições planetárias

O Atlas Solar usa os elementos keplerianos e taxas da Tabela 1 de “Approximate Positions of the Planets”, do Solar System Dynamics Group do Jet Propulsion Laboratory. O intervalo adotado é 1800–2050 e o referencial é a eclíptica/equinócio médio J2000.0.

Fonte: https://ssd.jpl.nasa.gov/planets/approx_pos.html

As posições são aproximações heliocêntricas de dois corpos. Para navegação operacional ou alta precisão, o próprio JPL recomenda o sistema Horizons.

Horizons: https://ssd.jpl.nasa.gov/horizons/

Constante astronômica usada: 1 UA = 149.597.870,7 km.

Fonte: https://ssd.jpl.nasa.gov/astro_par.html
